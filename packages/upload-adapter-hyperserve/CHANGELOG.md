# Changelog

All notable changes to `@hyperserve/video-uploader-adapter-hyperserve` are
documented in this file. This project adheres to
[Semantic Versioning](https://semver.org).

## [0.1.3-rc.0] - 2026-08-11

Prerelease published under the `next` tag to verify that releases authenticate
over npm trusted publishing from CI. Functionally identical to 0.1.2; the only
manifest change is the canonical `git+https://` repository URL that provenance
attestation matches against. `latest` is unaffected.
